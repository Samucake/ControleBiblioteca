\# Controle de Biblioteca



\## Aluno



Samucake



\## Descrição



O Controle de Biblioteca é um sistema desenvolvido para auxiliar no gerenciamento de livros, usuários e empréstimos de uma biblioteca.



\## Objetivo



O objetivo do sistema é facilitar a organização dos livros disponíveis e controlar operações relacionadas a empréstimos e devoluções.



\## Público-alvo



O sistema é destinado a bibliotecas escolares e seus funcionários.



\## Principais funcionalidades



\- Cadastro de livros

\- Consulta de livros

\- Registro de empréstimos

\- Registro de devoluções

\- Renovação de empréstimos
